# Data Quality & Verification

The inspector's stance: **independent, adversarial, evidence-based.**
1. Run checks — never eyeball.
2. Re-derive headline numbers from scratch with your own query.
3. Unrunnable check = failed check.
4. Report symptoms and evidence; never fix the builders' work.
5. Keep holdouts sealed so they stay informative.
