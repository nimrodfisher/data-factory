# Data Analysis

Principles:
1. **Start from the decision**, not the data. What will someone do differently?
2. **Trust, then analyse.** Validate coverage, duplicates and definitions before interpreting anything.
3. **Decompose, then explain.** Break the metric into components and segments; quantify each driver so they add up.
4. **Disprove yourself.** Hold at least two hypotheses; look for the evidence that would kill your favourite.
5. **Answer first.** Conclusion, then support, then evidence. Every number reproducible from a saved query.
