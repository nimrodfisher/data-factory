# Data Science

Principles:
1. **Frame before you fit.** Target, unit, decision, cost of errors, evaluation metric.
2. **Baseline first.** A model that does not beat a naive baseline does not ship.
3. **Validate like production.** Time-based splits for temporal data, grouped splits for repeated entities, hunt leakage.
4. **Quantify uncertainty.** Intervals, not point estimates.
5. **Simplest model that meets the bar.** Explainability is a feature.
