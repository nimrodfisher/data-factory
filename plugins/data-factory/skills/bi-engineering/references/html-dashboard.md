# Self-contained HTML dashboard (fallback)

Use when `stack.bi: html`, when no BI tool is reachable, or for a shareable snapshot. Requirements:
- **One file, zero external dependencies** (no CDN): inline CSS, inline JS, data embedded as JSON.
- Generated by a script (`build_dashboard.py` or similar) from mart queries, so it is reproducible — never hand-typed numbers.
- Header with title, date range, and "Data as of <timestamp>".
- KPI row → trend → breakdown → table, following `dashboard-design.md`.
- Charts drawn as inline SVG by small JS functions (line, bar, waterfall). Keep the chart code < 150 lines.
- Works offline, prints cleanly, readable on mobile (CSS grid with a single-column breakpoint).

## Minimal structure
```html
<!doctype html><html><head><meta charset="utf-8"><title>…</title><style>/* tokens, grid, tiles */</style></head>
<body>
  <header><h1>Question the dashboard answers</h1><p class="meta">Range · Data as of …</p></header>
  <section class="kpis"><!-- tiles rendered from DATA.kpis --></section>
  <section class="chart" id="trend"></section>
  <section class="chart" id="breakdown"></section>
  <section><table id="detail"></table></section>
  <script>const DATA = /* json embedded by the build script */;
  /* tiny SVG chart helpers + render calls */</script>
</body></html>
```
The demo in this repo (`examples/mrr-drop/build.py` → `dashboard.html`) is a working reference implementation.
